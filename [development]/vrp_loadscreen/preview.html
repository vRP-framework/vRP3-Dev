Live boot screen preview

This is the actual html/index.html running as-is (same CSS/JS as in-game) -- not a re-creation, so it stays accurate as style.css changes. It boots, fades into the slideshow, and starts tips/music same as a real connect. Progress bar stays at 0% here since that's driven by FiveM's own loading-screen events (startInitFunctionOrder / initFunctionInvoking / startDataFileEntries / performMapLoadFunction), which only fire in-game. After about a minute the safety-net timer will kick it into "Initializing..." anyway, but it'll never actually close here since vRP itself never confirms ready outside the game.

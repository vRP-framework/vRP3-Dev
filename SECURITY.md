# Security Policy

Report exploitable vulnerabilities privately before public disclosure.

Review these areas carefully:
- RegisterNetEvent handlers
- Tunnel and Proxy interfaces
- permissions and groups
- identity and character ownership
- money and inventory changes
- vehicle ownership
- police actions
- administration and moderation
- dynamic SQL or dynamic code
- rate limiting
- logging and audit integrity

Required controls:
- input validation
- server authority
- permission validation
- ownership/state validation
- rate limiting
- structured audit logging
- failure-safe behavior
